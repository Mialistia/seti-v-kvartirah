# Главная

Сайт — практическое руководство по подбору и организации сетевого оборудования (роутеров, коммутаторов, точек доступа, Mesh-систем) в квартирах с учётом площади, планировки и материалов стен.


## Для кого

- **Конечным пользователям** — понять, какое оборудование нужно именно их квартире и где его поставить.
- **Монтажникам** — пройти обследование, рассчитать покрытие и собрать рабочую схему сети по единой методике.

## Как пользоваться

1. Пройдите **чек-лист обследования** квартиры.
2. Определите **класс квартиры** (К1–К5).
3. Пройдите **пошаговый алгоритм** или воспользуйтесь **калькулятором подбора**.
4. Найдите похожую квартиру в **каталоге типовых схем** и выберите **готовую конфигурацию** (бюджетная, оптимальная, премиальная).
5. После монтажа проверьте результат по **протоколу замеров**.
